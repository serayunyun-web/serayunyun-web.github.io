## 一、新增商品「一般影印」（含彩色）

### 現況
- 商品清單在 `src/data/catalog.ts`，可下單商品是 `orderableProducts`。
- 自動計價規格與價格在 `supabase/functions/_shared/pricing.ts`，價目表是 `price-table.generated.ts`（由 Excel 產生）。
- **影印價格已有**：2026-11-16 確認、已實作在 `pricing.ts` 的「內頁印刷費」（`printRates`、`printLines`、`printSizeOf`、`innerSheets`），目前只用在裝訂產品的內頁。

### 已確認的價格與算法（沿用，不另做）
| 元／張（含紙張費） | A4 單面 | A4 雙面 | A3 單面 | A3 雙面 |
|---|---|---|---|---|
| 黑白 | 0.6 | 1 | 0.8 | 1.2 |
| 彩色 | 3 | 6 | 5 | 8 |

- 雙面＝一張紙正反兩面的價錢。
- 每一行 = 單價 × 張數 × 份數，**每一行小計算完再四捨五入**。
- 尺寸對照：B5、A5 照 A4；B4、25×25 照 A3；橫式同直式。
- 所有紙種同價，紙種只影響厚度（影印商品不需要厚度）。
- 混合印刷：彩色張數、黑白張數分開各算一行。

### 規劃
1. `catalog.ts` 新增商品 `photocopy`「一般影印」，放在「加工服務」分類，含商品頁、圖片（先用 placeholder）。
2. `pricing.ts` 新增 `photocopy` 計價規則，**直接重用 `innerFields` 和 `printLines`**，不重複寫價目：
   | 欄位 | 一般客人 | 設計師模式 |
   |---|---|---|
   | 尺寸 | A4／A3（B5、A5、B4 依對照表） | 同左 |
   | 內頁印刷 | 黑白／彩色 | 黑白／彩色／混合（填彩色張數） |
   | 單雙面 | 單面／雙面 | 同左 |
   | 頁數 | 每份頁數 | 可改用張數直接輸入 |
   | 紙張 | 預設 80g 道林紙、不顯示 | 完整紙種清單 |
   | 份數 | 沿用共用「製作數量」 | 同左 |
   - 影印商品要拿掉「不需要印刷（自備已印好內頁）」選項和封面紙張欄位。
   - 只有印刷費、沒有裝訂費。要裝訂的客人改選其他裝訂商品（裝訂商品本來就含內頁印刷費）。
3. **一般影印一定要有檔案**：這個商品的檔案欄改成必填，送出前檢查有沒有附檔。
4. 下單頁、估價頁、工作單、Email 報價單都要能顯示這些規格（`spec-labels.ts` 補標籤）。
5. `pricing.test.ts` 補測試：黑白 A4 雙面、彩色 A3 單面、混合印刷、B5 照 A4 價、四捨五入。

## 二、估價頁「用這個規格下單」後，先停在上傳檔案

### 現況
- 估價頁 `quote-catalog.tsx` 呼叫 `handOffQuote()` 後導向 `/order/?from=quote`。
- 下單頁 `order-request-form.tsx` 偵測 `from=quote`，**直接捲到 STEP 03 聯絡與配送**，會跳過：
  - 估價頁沒有的欄位：燙金內容、封面顏色／樣品編號、希望完成日期、製作名稱、備註、皮面樣品
  - 製作檔案上傳
- 客人可能不知道還有資料要補，也不知道要不要附檔。

### 規劃
1. **改捲動位置**：`from=quote` 時捲到 STEP 02 規格區頂端（不是聯絡區），讓客人從規格開始往下確認。
2. **彈出視窗提示**（已拍板；客人按按鈕關掉，同一筆帶入只跳一次）：
   > 已帶入你在估價頁選的規格。
   > 請確認以下內容：
   > - 估價頁沒有的欄位（燙金內容、皮面樣品、希望日期、備註）
   > - 是否有製作檔案要上傳（沒有可以之後再用 Email 或 LINE 提供）
   >
   > [我知道了，開始確認]
3. **標出「待補欄位」**：從估價頁帶來的欄位顯示「已帶入」小標；估價頁沒有、但該商品會用到的欄位（例如有選燙金卻沒填燙金內容）加醒目框。
4. **上傳檔案區加重點提示**（已拍板：不新增「是否有製作檔案」題目）：
   - 檔案區改成醒目的提示框（強調色邊框＋圖示），標題例如「📎 有製作檔案嗎？記得在這裡上傳」。
   - 說明文字：「需要印刷的內容（論文、封面、燙金 Logo 等）請在此上傳；已印好只需裝訂可略過。之後才有檔案，也可以用 Email 或 LINE 提供。」
   - 從估價頁帶過來時，提示框加一次閃爍／高亮動畫，讓客人一定看到。
   - 送出前的確認區：沒有附檔時顯示一行提醒「本次未附檔案」，不擋送出。
   - 一般影印商品例外：檔案必填（見第一項）。

## 三、皮革改成下拉選單（自動區分傳統／數位燙金）

### 現況
- 皮革資料在 `src/data/material-samples.ts`，每個色號已有 `digitalFoil`：
  - 皮紋系列 C／D（20 色）：可數位燙金，也可傳統燙金
  - 翡翠 J、珠光 P、絲光 B、雲龍 Y、單色 B／N：僅傳統燙金
- 下單頁現在只能按「看樣品冊」跳去樣品頁挑，再跳回來；另有一個自由輸入的「封面顏色／樣品編號」文字欄。

### 規劃
1. 在下單頁（與估價頁，若該商品有皮面）新增**皮革色號下拉選單**，依系列分組：
   ```
   ── 皮紋系列（可數位燙金）──
   C10、D11、C20 …
   ── 翡翠系列（僅傳統燙金）──
   J10、J20 …
   ```
   **每個選項顯示皮革縮圖**（已拍板）：原生 `<select>` 不能放圖，所以要做自訂下拉元件（可鍵盤操作、手機好點選），縮圖用 `material-samples.ts` 既有的 webp 圖。
   保留「看樣品冊」按鈕，給想看大圖的人用；樣品冊選完帶回來會同步到下拉選單。
2. **與燙金方式連動**：
   - 選了數位燙金 → 下拉只列皮紋系列（或其他系列變灰並註明「不可數位燙金」）。
   - 先選了非皮紋系列皮革 → 燙金選項中的「數位燙金」變灰，並提示「此皮革僅能傳統燙金」。
   - 計價與送出前驗證同一條規則，前後端一致（放在 `_shared` 共用）。
3. 只在封面是皮面時顯示（沿用 `when` 條件）；施工本只顯示「施工本專用皮」。**證書夾的皮面共用同一份色號**（已拍板）。
4. 原本的「封面顏色／樣品編號」自由輸入欄**維持現況**，不刪也不改名（已拍板）。
